# Project Title Options

Candidates for the project/presentation title. The method: an ifBO
(in-context freeze-thaw Bayesian optimization) optimizer that dynamically
samples candidate configs, uses a pretrained FT-PFN surrogate with
MFPI-random acquisition to decide which config to "thaw" next and for how
long, and maintains an epsilon-greedy explore/exploit balance plus an
incumbent ensemble at the end. Applied to text classification (BiLSTM /
transformer approaches).
